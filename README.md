## 🚀 About Me

I build enterprise-grade mobile applications that survive contact with millions of real users — in healthcare, insurance, and e-commerce, where reliability isn't optional. Over 13+ years I've moved from writing features to owning architecture, and lately from shipping apps to shipping autonomous AI agents that automate the engineering process itself. What drives me is the same thing in both worlds: turning messy, high-stakes requirements into systems that just work.

- 🚀 I'm currently working on **Agentic AI workflows for Abbott's Lingo app**, using LangGraph, CrewAI, and n8n to automate engineering delivery.
- 🌱 I'm currently learning **multi-agent system design and production RAG pipelines**.
- 👯 I'm looking to collaborate on **open-source tools bridging mobile engineering and LLM orchestration**.
- 💬 Ask me about **Clean Architecture, SwiftUI, Flutter, LangGraph, CrewAI, MCP, or n8n automation**.
